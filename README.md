# MereorFuck

一个专为 Paper 服务端设计的反作弊插件，旨在拦截并处理包括 Meteor 等客户端在内的违规行为。

## 📖 简介

**MereorFuck** 是一款轻量级、高性能的反作弊系统。项目基于 Java 和 Gradle 构建，针对 Paper 服务端 26.1+ 版本环境进行了深度优化。主要针对“流星”（Meteor）等常见作弊客户端的功能进行拦截与反制。

## ⚙️ 运行环境

- **服务端核心**：Paper 26.1 或更高版本
- **Java 版本**：Java 25+（由于包含了 mcreator.gradle（因为我是用VScode接管了mcreator造的工作区），请确保运行环境与构建环境一致）
- **前置依赖**：无（视实际功能可能包含软依赖，如 ProtocolLib，请根据实际构建情况调整）

## 📦 下载与安装

> **重要提示：本项目的源码及编译产物统一存放在 Releases（发行版）中，请勿直接克隆当前分支作为最终版本使用。**

1. 前往本仓库的 [Releases](https://github.com/Lenjing2026/MereorFuck/releases) 页面。
2. 在最新版本（Latest）的 Assets 中下载源码包或编译好的插件 `.jar` 文件。
3. 将 `.jar` 文件放入服务端的 `plugins` 文件夹。
4. 重启服务端，插件将自动生成配置文件。
